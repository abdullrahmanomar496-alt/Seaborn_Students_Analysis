Students Performance Analysis with Seaborn

Project Overview

This is a beginner Python project where I explored a student performance dataset using Pandas, Seaborn, and Matplotlib.

The goal was to practice data visualization and explore patterns in student performance data.

Tools Used

- Python
- Pandas
- Seaborn
- Matplotlib
- Jupyter Notebook

Visualizations

In this project, I created:

- Count plots to explore study time categories
- Box plots to compare final grades
- Scatter plots to explore absences and grades
- Correlation heatmaps
- Violin plots to visualize grade distributions
- Pair plots to explore relationships between variables

I also practiced customizing chart colors and comparing groups using the "hue" parameter.

Dataset

The project uses the Student Performance dataset.

Dataset source: "UCI Machine Learning Repository" (https://archive.ics.uci.edu/dataset/320/student+performance)

The file used in this project is "student-mat.csv".

What I Learned

This project helped me practice creating statistical visualizations and exploring relationships between numerical variables using Python.

I am continuing to improve my data analysis skills through hands-on projects.
